# Contributing

Thanks for your interest in this project.

This repository is published for **learning, experimentation, and personal use**.

## Forks

- Forks are **welcome**.
- You are free to modify the code in your own fork.
- You may maintain and distribute your fork **for non-commercial purposes**, in accordance with the project license.

## Pull Requests

- **Pull requests are not accepted.**
- This repository is maintained as a personal project with a specific architecture and roadmap.
- Please do not open PRs expecting review or merge.

## Issues

- Issues may be used for:
    - bug reports
    - clarification questions
    - discussion

- Feature requests may be read, but there is **no guarantee** they will be implemented.

## Commercial Use

- Commercial use is **not permitted** under the current license.
- If you are interested in commercial use, contact the repository owner to discuss licensing options.

## Code Style & Direction

- The codebase prioritizes:
    - clarity over abstraction
    - explicit state ownership
    - minimal magic
- Architectural decisions are intentional and may differ from common frameworks or patterns.
